# Order Calling System

簡易區網點餐 / 叫號系統。

## 功能

- 筆電作為主機與管理控台
- 手機透過同一 Wi-Fi 開啟網頁點餐
- 一張訂單只能選擇一個品項
- 自動產生叫號號碼
- WebSocket 即時同步
- 手機重新整理後可恢復目前訂單
- 叫號時手機震動、畫面提示、播放提示音
- 控台可叫號、重新叫號、完成訂單
- 控台可新增 / 刪除菜單品項
- 控台可清空全部訂單並重設號碼

## 啟動

需要 Node.js 18 以上版本。

```bash
npm install
npm start
```

啟動後：

- 客戶端：http://localhost:8080/
- 控台：http://localhost:8080/admin

## 手機連線

手機與主機必須位於同一個 Wi-Fi / 區網。

### macOS 查詢 Wi-Fi IP

```bash
ipconfig getifaddr en0
```

例如顯示：

```text
192.168.1.123
```

手機瀏覽器開：

```text
http://192.168.1.123:8080/
```

## 注意

目前訂單、菜單與號碼只保存在主機記憶體中。

若重新啟動 Node.js：

- 訂單會清空
- 菜單恢復預設值
- 號碼重新從 1 開始

這是刻意維持最小架構，適合活動 / 攤位短期使用。

另外，手機瀏覽器若完全進入背景或被系統休眠，WebSocket 可能被中斷，因此這不是可靠的系統通知服務。現場使用時建議讓叫號頁保持開啟。
